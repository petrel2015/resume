# 面试与简历：Spark-Performance-Insight 项目复盘

## 1. 项目目标与痛点定位 (Why & What)
- **痛点**: Spark 原生 Web UI 加载 GB 级日志慢（2h+）、易 OOM；指标堆砌无重点，缺乏直观调优建议。
- **目标**: 构建秒级解析、智能诊断的工具，实现从“数据过载”到“行动建议”的转化。

## 2. 现代技术栈 (Tech Stack)
**核心栈**: Java 21 (虚拟线程) / Spring Boot 3 / Vue 3 / DuckDB (嵌入式 OLAP)。
- **AI 协作**: 深度利用 **Gemini CLI**。作为架构副驾完成 Vue3 补齐、规范审计与工程自动化。

## 3. 技术突破与亮点 (Highlights)
- **24 倍性能翻转**: 针对 2GB 日志解析，引入**奖章架构 (Medallion Architecture)**，利用 DuckDB 原生 JSON 加载特性将耗时从 **120min 优化至 5min**。
- **红绿灯视觉反馈**: 自研 9 维指标评分系统。通过三色灯直观呈现瓶颈，满足初学者（看 AI 报告）与专家（秒级定位红灯 Stage）的双重需求。

## 4. 工程质量与自动化看护 (Guardrails)
- **规范防线**: 固化**阿里巴巴 Java 规范 Skill**，实现代码实时审计。
- **性能看护**: 集成 **JMH 性能测试**，看护 5 分钟解析成就，防止版本迭代退化。
- **自动化闭环**: 配置 GitHub Actions CI；沉淀状态机与建模文档，确保持续可维护。

## 5. 面试 1-2 分钟自述稿

我采用了 **Java 21 + DuckDB + Vue3** 的现代技术栈。整个过程中，我利用 **Gemini CLI** 作为全栈副驾，高效补齐了前端工程化的短板。
